## 🎮 Overview / 概要

[EN] This is a command-selected turn-based battle simulation game.

| Category / 項目 | Details / 内容 |
| :--- | :--- |
| **Genre / ジャンル** | Command Battle / Turn-based Battle / Simulation (コマンド式バトル / ターン制バトル / シミュレーション) |
| **Players / プレイ人数** | 1 Player (1人) |
| **Environment / 開発環境** | OpenSiv3D / C++ |

## 💻 System Requirements / 動作環境
- **対応OS**: Windows 11
- **Memory / 推奨スペック**: 8GB RAM or higher (メモリ 8GB 以上)

## 🕹️ Controls / 操作方法

| Key / キー | Action (EN) | 操作内容 (JP) |
| :---: | :--- | :--- |
| **`W` / `S`** | Command Navigation | コマンド操作 |
| **`A` / `D`** | Target Selection | 攻撃対象選択 |
| **`C`** | Cancel | 操作キャンセル |
| **`SPACE`** | Confirm | 操作決定 |
